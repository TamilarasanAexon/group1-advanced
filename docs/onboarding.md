# Developer Onboarding

1. Create a repository from the standard template.
2. Update application metadata.
3. Run tests locally.
4. Build the container locally.
5. Run Terraform validation.
6. Push a branch and open a pull request.
7. Review CI/security results.
8. Merge only after required checks pass.
9. Use the release workflow for environment packaging/deployment.

The platform team owns reusable workflows, modules and standards. Application teams own business logic and service-specific configuration.
